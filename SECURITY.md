# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Report them
privately through GitHub's "Report a vulnerability" feature on this repository
(Security tab → Advisories).

We aim to acknowledge reports within 5 business days. Because this project
contains `unsafe` SIMD code, reports of memory-safety issues (out-of-bounds
access, misalignment, undefined behavior) are especially welcome.

## Supported versions

The project is in the design phase; no released versions are supported yet.
